# Real artwork references & licenses

The card uses **external real paintings / sculpture photographs, not AI-generated artwork**. The runtime prioritizes local `assets/images/*.jpg`; if absent it requests the same works directly from Wikimedia Commons. The downloadable originals are documented in `assets/images/art_manifest.json`.

1. **The Birth of Venus** — Sandro Botticelli (c. 1485), Uffizi. Public Domain / PD-Art. https://commons.wikimedia.org/wiki/File:Nascita_di_Venere_Botticelli.jpg
2. **Psyche Revived by Cupid's Kiss** — marble sculpture by Antonio Canova (1793); Louvre. Photo Siren-Com, released to public domain. https://commons.wikimedia.org/wiki/File:Antonio_Canova_-_Psyche_revived_by_the_kiss_of_Love,_Marble,_1793.jpg
3. **Primavera** — Sandro Botticelli. Public Domain / PD-Art. https://commons.wikimedia.org/wiki/File:Botticelli_Primavera.jpg
4. **The Three Graces** — Raphael (c. 1504–1505), Musée Condé, Google Art Project. Public Domain / PD-Art. https://commons.wikimedia.org/wiki/File:Rapha%C3%ABl_-_Les_Trois_Gr%C3%A2ces_-_Google_Art_Project.jpg
5. **Venus and Mars** — Sandro Botticelli, WGA2776 variant. Public Domain / PD-Art. https://commons.wikimedia.org/wiki/File:Sandro_Botticelli_-_Venus_and_Mars_-_WGA2776.jpg
6. **Pompeii, winged Cupid and Psyche** — historic recording by Wilhelm Zahn (d. 1871). Public Domain / PD-Art. https://commons.wikimedia.org/wiki/File:Fresco_depicting_winged_Cupid_and_Psyche_from_the_west_wall_of_the_exedra_in_the_Casa_di_Bronzi_aka_Casa_della_Parete_Nera_in_Pompeii_by_Wilhelm_Zahn.jpg

All artworks are colored, cropped and layered with CSS to fit pastel-lavender paper design. Each attribution is also preserved as part of the card package.

**Piaget**: The final platinum-colored pair of wedding bands is a hand-coded Canvas 3D rendering inspired by the visual character of Piaget's publicly described platinum bands, and is **not** a genuine Piaget product photo or guarantee of the exact design. Official reference: https://www.piaget.com/us-en/wedding/platinum-wedding-rings

**Music**: `pastel-waltz-demo.mp3` is an original synthesized demo soundtrack, not a recreation/download of the requested commercial remix. Add a legally obtained MP3 you are permitted to use, per `config.js`.

**Personal video**: `demo-memory.mp4` is a generated code-based placeholder, not the user's intended local video.
